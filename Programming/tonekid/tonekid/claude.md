Here is the full prompt with the black and white minimalist design integrated. Copy this entire block into Cursor as your project brief.
Build a complete React Native frontend MVP of ToneKid, a guitar tone-matching app that adapts famous song tones to the user's specific gear. Frontend only, no backend, all data mocked. Use Expo with TypeScript, NativeWind for Tailwind CSS support, React Navigation for routing, Lucide React Native for icons, and React Native Reanimated for animations. The app must run on iOS Simulator end to end with every screen navigable and every interaction functional even if data is fake.
Tech setup
Initialize a new Expo project with TypeScript template. Install nativewind tailwindcss react-native-reanimated react-navigation/native react-navigation/native-stack react-navigation/bottom-tabs lucide-react-native expo-linear-gradient react-native-svg react-native-safe-area-context. Configure Tailwind with NativeWind. Use SF Pro Display via the system font on iOS. Configure deep nested gesture handlers as needed.
Visual design system
Direction is minimalist black and white with editorial polish. Think Apple, Linear, Arc Browser applied to a music app. The aesthetic is unforgiving by design, every spacing decision and typographic choice should feel intentional. Color is used very sparingly as accent only.
Background base pure white FFFFFF. Surface for cards, inputs, and chips light gray F4F4F5. Surface elevated when nesting needed EEEEF0. Border hairline E5E5E7, used very sparingly because surface contrast does most of the separation work. Text primary near-black 0A0A0A. Text secondary 6B7280. Text muted 9CA3AF.
Primary brand color is black 0A0A0A. All primary buttons, active tab states, and key UI accents are black on white or white on black. There is no brand blue or amber as the primary color.
Accent colors are used semantically and very sparingly. Green 10B981 for success states, exact matches, and the favorite heart icon (filled when favorited). Amber F59E0B for critical warnings and the upgrade crown only. Red EF4444 for limits and errors. Soft pastel pills for tone category tags inside the Tone Detail screen only. Light purple background EDE9FE with darker purple text 7C3AED, light pink background FCE7F3 with pink text DB2777, light blue background DBEAFE with blue text 2563EB, light green background D1FAE5 with green text 059669. These pastel pill backgrounds appear only inside Tone Detail, not in main navigation or buttons.
Typography. Headlines weight 800 in a clean sans like SF Pro Display or Inter, tight tracking at -0.02em, very large at 32 to 40px on key screens. Body weight 400 to 500. Section labels are uppercase tracked at letter-spacing 0.08em weight 600 at 11px in muted gray. Numerical values and parameter readings use weight 700.
Spacing. 4 point base. Generous breathing room. Card padding 20 to 24px. Section gaps 32 to 40px.
Borders and radius. Larger cards use rounded-3xl (24px) for the active setup card and key feature cards. Standard cards rounded-2xl (16px). Inner cards rounded-xl (12px). Pills rounded-full. Inputs rounded-2xl. Primary CTAs rounded-full to match the soft minimalist aesthetic. Secondary buttons rounded-2xl.
Shadows. Almost none. The surface contrast between white background and gray cards does the lifting. If shadow is needed for floating elements like the tab bar or playback bar, use a very soft long shadow at 4 to 6 percent opacity, large blur radius, low offset.
Buttons. Primary button is solid black background 0A0A0A with white text, rounded-full, weight 700, padding y-4 px-6. Secondary button is light gray F4F4F5 background with black text, same shape. Ghost button is transparent with black text and no border. Disabled state is opacity 40 percent. Active press state is a slight darken to 1A1A1A.
Tab bar. Floating pill at the bottom, 16px from bottom edge with horizontal margin 16px. Background is light gray F4F4F5 with subtle shadow. 5 tabs evenly distributed. Active tab has a black filled circle behind the icon at 44x44 with white icon inside. Inactive icons are near-black at 70 percent opacity with no background. No labels under active icons, optional muted labels for inactive tabs (or no labels at all for a cleaner look, pick what looks better).
Pills throughout the app. Filled pills use light gray F4F4F5 background with near-black text. Outline pills use transparent background with hairline border and near-black text. Selected pill in a filter row uses solid black background with white text. Status pills use the pastel semantic colors only when conveying status, never as decoration.
Search inputs and form inputs. Light gray F4F4F5 background, no border, rounded-2xl, padding y-3 px-4, leading icon in muted gray 9CA3AF, placeholder text in muted gray. Focus state subtly darkens the background to EEEEF0.
Cards on the Tone Detail screen. Pure white with very subtle shadow, rounded-2xl, padded 20px. Each card has a small icon in a 40x40 rounded square on the left of the title, background F4F4F5 with the icon in black at 20px.
Album art and gear placeholders. 1:1 aspect ratio rounded-xl images. When no real image is available, use a light gray F4F4F5 placeholder with a centered small icon in muted gray.
Active setup card on My Gear. Rounded-3xl light gray F4F4F5 background, no border. Inside it, two pure white rounded-2xl tiles for the guitar and amp icons with their names, and a black arrow between them.
Onboarding illustrations. Monochrome line illustrations or single-color black icons inside a large F4F4F5 rounded square at 120x120. This keeps onboarding feeling cohesive with the rest of the app.
Paywall modal. White background, rounded top corners only since it slides up as a sheet. The "Save 58%" pill in the yearly card uses one of the only spots of color, a small green pill. The CTA button is solid black with white text, rounded-full. The "Maybe later" dismiss is ghost text in muted gray.
Splash screen. Pure white background, centered ToneKid logo in black, small tagline below in muted gray. No color, no gradient.
Navigation architecture
Root navigator is a stack. First screen is Splash. After splash, check a mock auth state. If unauthenticated, show Welcome stack containing Welcome, Onboarding (3 steps), Sign In, Sign Up screens. If authenticated, show MainTabs.
MainTabs is a custom bottom tab navigator with 5 tabs. Explore, My Tones, Adapt, My Gear, Profile. The tab bar uses the custom floating pill design described above.
From any tab, additional stack screens can push on top. AdaptFlow contains 3 substeps (Your Gear, Pick a Song, Results). Tone Detail screen is pushed when tapping any tone. Add Gear flow is pushed from My Gear. Paywall modal is pushed contextually. Settings sub-screens push from Profile.
